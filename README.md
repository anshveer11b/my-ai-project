# Omen's Ai 🔮

Omen's Ai is a full-stack Python web application featuring an interactive front-end and a fast, robust backend API. The project is containerized using Docker and continuously deployed to the cloud via Render.

## 🚀 Live Demo
**[View the Live Application Here](https://omens-ai.onrender.com)**

*(Note: The application is hosted on a free Render tier. If it has been inactive for 15 minutes, it may take ~50 seconds to wake up on the first load).*

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI, Uvicorn
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Environment/Containerization:** Docker
* **Deployment & Hosting:** Render (Cloud PaaS)
* **Version Control:** Git, GitHub

## 📂 Project Structure
* `main.py`: The main FastAPI application serving the API endpoints and connecting the AI logic.
* `index.html`: The frontend user interface that interacts with the API.
* `requirements.txt`: Clean, unpinned Python dependencies optimized for cloud deployment.
* `Dockerfile`: The container instructions used by Render to build the environment.
